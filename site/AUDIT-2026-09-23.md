## 已有能力及验证范围

本地从公开仓库文件构建得到 111 个 HTML 页面、30 篇文章、7 个专题、2 个 Skill、48 个 Sitemap URL、30 条 RSS 文章和 11 个旧地址跳转。校验包括文章与元数据的一一对应、canonical、Open Graph、JSON-LD、Sitemap 与 noindex 关系、标签/层级成员、站内链接与锚点、静态资源、搜索去重与排序、公式保护、JavaScript 语法及跳转参数保留。

现有首页看板、角色素材、主题切换、代码复制、工程图、阅读位置和阅读地图保留。主题视觉不需要为解决目录和搜索问题整体重做。

线上浏览器确认了原版目录与搜索问题；响应式 CSS 已修改，手机实机表现仍需单独验证。CDN 加载、浏览器交互与上线状态需要结合实际部署再检查，静态校验不等于浏览器端全部功能通过。

## 尚未能确定的事情

- `site/search-console.json` 没有验证 token；这只能证明未通过该配置输出验证标签，不能证明用户没有用其他方法验证 Search Console。
- 没有 Search Console 权限和数据，无法判断实际收录数量、抓取错误、搜索词、排名或点击率。
- 没有真实用户性能数据，不能宣称 Core Web Vitals 达标或优化带来流量增长。
- 本轮检查站内链接与章节目标，不代表所有上游外链长期可达，也不代表所有文章中的实现结论已经重新核实。

有效 robots.txt 必须由 GitHub Pages 域名根目录提供；本项目子路径不伪造根级抓取规则。已有 Sitemap、RSS 和 canonical 继续保留。
