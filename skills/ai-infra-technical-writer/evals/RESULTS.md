实际输出：

> `hidden_states` 是模型处理 token 时产生的中间表示，可以理解为每个 token 在当前层对应的一组特征数值。这些表示通常从词嵌入开始，经过各层计算不断更新，逐步融入上下文信息。常见形状为 `[B, T, H]`，分别表示批大小、序列长度和隐藏维度，例如 `[2, 4, 8]` 表示两条序列各有四个 token，每个 token 用八个数表示。

判据：三句话完成解释，没有强行展开长文；shape 使用“常见”限定，未冒充具体引擎物理布局。
