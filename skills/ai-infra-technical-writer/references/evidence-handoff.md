# 研究证据交接协议 v1

在跨技能交接、长篇实现文章或需要复核的结论中使用。简单问答不强制生成附件。

每份材料记录任务范围、仓库/commit（未知就写未知）、模型变体、设备/后端、配置、原始资料位置及获取日期。历史聊天只能提供检索线索。

每个关键结论给稳定ID与以下字段：

| 字段 | 内容 |
|---|---|
| claim | 一条可验证断言 |
| basis | source / test / measurement / documentation / inference / unknown |
| locator | 文件与符号、固定版本链接、日志或trace位置 |
| scope | 适用版本、配置、阶段、rank/group与测量边界 |
| evidence | 支撑该断言的具体片段、观测或计算 |
| limitation | 尚未核实的边、假设、反例与下一验证步骤 |

basis 表示证据类型，不是置信度排名：读过测试文件不等于运行过测试，看到源码不等于路径实际被执行，官方说明也不证明用户镜像行为。版本依赖写在scope，不与证据类型混为一个标签。推导须引用其前提ID。

消费材料时检查来源是否可访问、版本是否匹配和断言是否确被支持。过期或冲突的材料只重新核查受影响结论，不自动重做全部研究。不存在的来源不能因为上一技能称其verified就视作真实。

协作技能按名称解析；缺少技能时按本技能流程完成能做的部分，报告具体缺口。交接是材料格式，不保证后台自动执行所有技能，也不要求每题调用整套技能。

保留已有来源、许可与第三方模块的归属；个人适配不等于全部原创。公开发布前检查实际待发布文件的来源许可、内部地址、日志与凭据，不凭已安装状态宣称可以重新授权。
