| Skill | 用途 | 入口 |
|---|---|---|
| AI Infra Technical Writer | 撰写、重写和审核 SGLang、DeepSeek、Ascend 等技术文章 | [介绍与使用](ai-infra-technical-writer/README.md) · [规则](ai-infra-technical-writer/SKILL.md) |
