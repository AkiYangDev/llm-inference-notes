# Worked Example：PR #39120

PR：`sgl-project/sglang#39120`，merge commit `24b6c1c7f5ba6c95a96acc9e77b4f5efb23eff97`。

## Impact Surface

Trigger：batched multimodal encoder 返回整体 Tensor，`torch.split` 后的 View 被长期 Cache。Symptom：Entry 按逻辑 payload 记账，但 View 继续保活整块 Batch Storage。Blast Radius 要按历史 Batch 的独立 Storage 分析，不能把同一 Batch 的多个 View 重复乘算。更准确术语是 unintended retention。

## Invariant

Cache Budget 必须约束 Cache Entry 实际保持存活的底层资源；per-entry additive accounting 不能让一个小 Entry 隐式 pin 住远大于自身账面的无关 Storage。

## Why This Fix

只把每个 View 按完整 Storage 记账会对共享 Storage 重复计费；实现选择在长期 ownership 边界对 oversized admitted View 做 clone，让 Entry 拥有紧凑独立 Storage，从而让简单的 per-entry accounting 重新成立。

## Validation Surface

PR 报告 CPU smoke checks 覆盖 ordinary、detached、strided、inference-mode slice、expanded Tensor、LRU accounting；GPU performance 和 model accuracy 未跑。Regression test 直接检查 cached Entry 的 storage bytes 与 payload bytes 对齐。

## Review Questions

- 这个 Tensor 是 owner 还是 View / alias？
- Entry 被长期保存后会额外保活什么 backing resource？
- eviction 后真正释放多少字节？
- accounting 粒度和 ownership 粒度一致吗？
- clone 应发生在计算路径，还是只有进入长期容器时？
